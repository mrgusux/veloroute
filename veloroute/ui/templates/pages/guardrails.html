📖 Client Request Headers Reference
Control guardrails programmatically on any /v1/chat/completions request via HTTP headers:
Header Allowed Values Description
x-guardrail-mode redact | block | off Enforces in-flight PII redaction or instant 400 rejection
x-injection-protection true | 1 Enables heuristic jailbreak and adversarial prompt detection
x-privacy-mode true | 1 Enforces per-request zero-retention privacy (skips cache and storage logs)
x-ratelimit-queue-timeout number (e.g. 5.0) Holds requests in an async queue instead of failing with 429
